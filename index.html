This dashboard is API-ready: the BP_API adapter in the source accepts an endpoint + key and maps JSON to the same session schema as CSV imports. When/if Beyond Pulse opens access, wire it through a Vercel serverless proxy (/api/beyondpulse) to avoid CORS — a config change, not a rebuild.
